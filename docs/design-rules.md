# 摄影网站设计规则

## 页面骨架

Logo 与主导航独立成行，在作品、简介和联系页面保持同一位置。作品工具行显示当前栏目与 Single / Multi，属于图库，不影响主导航布局。主页、分类、简介和联系使用共同的外边界，正文行宽在内部控制。

## 作品编排

照片保持原有顺序和完整构图。自动排版同时考虑观看尺度、同排照片比例差异与相邻行高度；每行最多三张，过高的行居中收窄，单张末行不拉伸铺满。手机为单列。

后台的 `presentation` 可为 `auto` 或 `solo`，`group` 为可选的编排组名。同名且相邻的照片不与其他组混排，长组可以换行，独立展示优先。旧数据没有这些字段时继续自动排版。分组不修改顺序，不自动精选或发布照片。

## 品牌与文字

文字 Logo 保留原先字体、基线和粉色条关系。共用 `app/design.css` 管理字体与颜色：品牌和页脚使用渐变，当前位置使用短粉色标记，视图切换使用文字深浅与细线。功能文字以 12px 为基础，简介和联系标题使用共同字阶。

前台不显示逐张照片标题或数量，辅助描述用于无障碍。照片悬停不改变亮度、色彩或构图。后台可使用更密集的布局，同时共用品牌、字体和基础控件颜色。

## 浏览行为

横幅、单张与全屏使用同一种箭头与 44px 点击区域，控件位于照片之外。全屏支持方向键、Escape 和滑动，关闭后返回当前照片。Single 转回 Multi 时定位到同一作品。单张和全屏仅预加载前后相邻照片。

## 检查

检查桌面、宽屏、平板和手机：导航不随页面或模式漂移；页面无水平溢出；每张照片保持原比例；视图切换与关闭预览能返回当前作品；分组和独立展示经过本机与 D1 保存后保留。
